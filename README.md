# 🐍 Python Programs

A collection of basic Python programs created for learning and practicing fundamental programming concepts.

## 📂 Programs Included

### 1. Struct Program
A Python program demonstrating the use of structured data and organizing related values.

### 2. Factorial Program
Calculates the factorial of a given number using a `for` loop.

**Example:**
```text
Enter a number: 5
The factorial of 5 is 120.
```

The program also handles:
- Negative numbers
- Zero
- Positive integers

### 3. Fibonacci Program
Generates the Fibonacci sequence up to a specified number of terms.

**Example:**
```text
Enter the number of terms: 7
Fibonacci sequence:
0 1 1 2 3 5 8
```

## 🛠️ Concepts Practiced

- Python input/output
- Variables and data types
- Conditional statements
- `for` loops
- Arithmetic operations
- Functions/logic
- Basic problem solving

## 🚀 How to Run

Make sure Python is installed on your system.

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd <repository-name>
```

Run any Python program using:

```bash
python filename.py
```
